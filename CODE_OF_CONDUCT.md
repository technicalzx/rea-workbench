# Community conduct

Treat people respectfully. Discuss code and evidence, avoid harassment and discriminatory language, and give credit for others' work. Keep issues and pull requests focused on the project.

Do not publish credentials, private samples, identifying investigation data, or instructions aimed at unauthorized harm in project discussions. Report sensitive security issues through SECURITY.md.

The repository owner moderates this project and may edit or remove abusive content, close disruptive discussions, or restrict participation. Reports about community conduct can request a private contact through the issue tracker without repeating private information publicly.
