# Changelog

## 0.1.0 — 2026-10-15

Initial local workspace: investigation management, notes, archive/restore, static REA analyses, evidence hashes, summary exports, configurable OmniRoute/OpenCode integration, and localhost dashboard. Includes a threat model, secure development practices, tests, dependency checks, and contributor workflows.

Early release. Windows Ghidra support depends on REA's experimental provider. Multi-user hosting, sandboxing, encrypted storage, signed evidence, and certified compliance are not implemented.
