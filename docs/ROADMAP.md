# Roadmap

## Available in 0.1

Local project management, four static workflow types, evidence history/hashes, notes, archive/restore, summary export, OpenCode/OmniRoute configuration, and a localhost dashboard.

## Next: reliability and security

- Independent threat-model/code review and focused penetration tests.
- OS-specific process-tree containment and resource ceilings.
- Fuzzing of HTTP/config boundaries and corrupted project recovery.
- Expanded real REA/Ghidra/OpenCode tests across Linux, macOS and Windows.
- Schema migrations, storage locking across CLI/dashboard processes, report import, and encrypted backup guides.
- Verified release provenance, license inventory review and signed release artifacts.
- Accessibility audit and automated keyboard/responsive UI checks.

## Community proposals

- Evidence search and structured report templates.
- Optional Git-backed metadata collaboration with secret-aware review before sync.
- Model capability/cost awareness and local inference setup assistants.
- Reviewed additional REA workflows; each has an explicit authority and data boundary.
- A separately designed authenticated team service with RBAC, audit trails, per-user credentials, sandboxed workers, storage encryption, and retention controls.

Hosted multi-user analysis, runtime instrumentation, arbitrary plugin execution, model quotas bypasses and unattended execution are not part of the current dashboard. Propose scope and security requirements before implementing substantial changes.
